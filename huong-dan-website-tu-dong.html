Tạo website tự động với Claude Cowork

Bạn chỉ cần đưa nội dung cho Claude — nó tự tạo file, đẩy lên GitHub, Vercel tự publish. Thêm bài mới sau này cũng vậy: nói là xong, không cần đụng code.

📝 Bạn viết nội dung
→
🤖 Claude tạo file
→
🐙 GitHub lưu
→
🌐 Live trên web
Nội dung bài này
1 Hiểu 3 công cụ cần dùng (5 phút) 2 Setup 1 lần duy nhất (30 phút) 3 Thêm bài mới bằng Claude Cowork (2 phút/bài) 4 Gắn tên miền riêng (tùy chọn)

Phần 1 — Hiểu 3 công cụ cần dùng

Trước khi làm, bạn cần hiểu mỗi thứ làm gì. Đọc xong 3 dòng này là đủ:

🔨 Docusaurus — thợ xây nhà

Đọc các file bài viết (.md) của bạn → tạo ra website hoàn chỉnh (HTML, CSS, JS). Chạy trên máy tính của bạn, chưa ai xem được từ internet.

🐙 GitHub — kho lưu trữ

Lưu toàn bộ code lên cloud. Khi bạn "push" code lên đây, Vercel sẽ tự biết và deploy ngay.

🚀 Vercel — mảnh đất + địa chỉ nhà

Nhận website từ GitHub → đặt lên server → cấp địa chỉ URL để cả thế giới vào được. Free. Tự động. Không cần làm gì thêm sau khi setup.

💡
Tóm lại trong 1 câu
Docusaurus xây nhà → GitHub giữ bản vẽ → Vercel đặt nhà lên mảnh đất có địa chỉ. Thiếu 1 trong 3 là không xong.

Phần 2 — Setup 1 lần duy nhất

Phần này bạn làm 1 lần duy nhất. Sau đó mọi bài mới đều do Claude Cowork làm hết.

1
Cài Node.js và Git
Công cụ nền tảng — cài 1 lần, dùng mãi mãi

Vào 2 link này, tải về và cài như phần mềm bình thường (Next, Next, Finish):

Node.js: https://nodejs.org — tải bản LTS (bên trái)
Git: https://git-scm.com — tải về cài mặc định

Kiểm tra đã cài xong chưa — mở terminal (Windows: nhấn Windows + R, gõ cmd) rồi gõ:

Terminal — kiểm tra cài đặt
node -v # Phải hiện ra v20.x.x gì đó git --version # Phải hiện ra git version 2.x.x
⚠️
Lưu ý chống ngáo
Nếu terminal báo lỗi "not recognized" — đóng terminal, mở lại, gõ lại. Cài xong phải mở terminal mới thì nó mới nhận.
2
Tạo project Docusaurus
Bộ khung website — chạy 1 lệnh là xong

Mở terminal, chọn thư mục bạn muốn lưu project (ví dụ Desktop), rồi chạy lệnh này:

Terminal
# Di chuyển vào Desktop (hoặc thư mục bạn muốn) cd Desktop # Tạo project — đặt tên tùy bạn, ví dụ "luoi-hr" npx create-docusaurus@latest luoi-hr classic # Chờ 1-2 phút... khi xong thì vào thư mục vừa tạo cd luoi-hr # Chạy thử trên máy để xem npm start

Trình duyệt sẽ tự mở http://localhost:3000 — đây là website của bạn chạy trên máy, chưa ai xem được. Bước tiếp theo sẽ đưa nó lên internet.

3
Đẩy lên GitHub
3 click + 3 lệnh — làm 1 lần

Vào github.com, đăng ký tài khoản nếu chưa có, rồi tạo repo mới:

① Nhấn nút New repository (góc trên phải)
② Đặt tên: luoi-hr
③ Chọn Public → nhấn Create repository
④ GitHub sẽ hiện ra các lệnh — copy phần "push an existing repository"
Terminal — trong thư mục luoi-hr
git init git add . git commit -m "first commit" git branch -M main git remote add origin https://github.com/TEN_BAN/luoi-hr.git git push -u origin main # Thay TEN_BAN bằng username GitHub của bạn
4
Kết nối Vercel — website live trong 2 phút
Chỉ cần làm 1 lần, sau đó tự động mãi mãi
① Vào vercel.com → đăng nhập bằng tài khoản GitHub
② Nhấn Add New Project
③ Chọn repo luoi-hr vừa tạo → nhấn Import
④ Vercel tự nhận ra là Docusaurus → nhấn Deploy
⑤ Chờ ~1 phút → website live tại luoi-hr.vercel.app
✅
Setup xong rồi — từ đây Claude Cowork làm hết
Mỗi khi bạn push code mới lên GitHub, Vercel tự động build và deploy lại. Bạn không cần vào Vercel nữa.

Phần 3 — Thêm bài mới bằng Claude Cowork

Đây là phần hay nhất. Sau khi setup xong, workflow của bạn chỉ còn thế này:

1
Mở Claude Cowork, kết nối vào máy tính
Cowork nhìn thấy màn hình và điều khiển máy bạn

Vào claude.ai → Cowork, cho phép kết nối màn hình. Cowork sẽ thấy toàn bộ thư mục project trên máy bạn.

2
Đưa nội dung bài mới cho Claude
Paste nội dung vào chat, Claude tự làm phần còn lại
Prompt mẫu — paste vào Claude Cowork
Đây là nội dung bài hướng dẫn tạo skill KPI: [paste nội dung vào đây] Hãy: 1. Tạo file docs/bi-kip/tao-skill-kpi.md với nội dung trên 2. Format đúng chuẩn Docusaurus (có frontmatter, heading) 3. Thêm Prompt Block cho mỗi prompt trong bài 4. git add, commit, push lên GitHub
3
Ngồi uống cafe, đợi 2 phút
Claude tạo file → push GitHub → Vercel tự deploy
🎉 Kết quả
luoi-hr.vercel.app/bi-kip/tao-skill-kpi

Bài mới live trên web. Sidebar tự cập nhật. Không cần sửa gì thêm.

ℹ️
Cowork cần gì để hoạt động trơn tru?
Git đã config username/email (làm 1 lần), SSH key đã kết nối GitHub, terminal đang ở đúng thư mục project. Nếu chưa có, nhờ Claude Chat hướng dẫn setup — chỉ mất 5 phút.

Phần 4 — Gắn tên miền riêng (tùy chọn)

Muốn có địa chỉ luoihr.com thay vì luoi-hr.vercel.app:

① Mua tên miền tại namecheap.com hoặc inet.vn (~200k/năm)
② Vào Vercel → Project Settings → Domains → Add Domain
③ Gõ tên miền của bạn → Vercel sẽ cho bạn 2 dòng DNS để copy
④ Paste 2 dòng đó vào DNS settings của nhà cung cấp tên miền
⑤ Chờ 5-30 phút → tên miền hoạt động
