# tempo/

Thư mục chứa **bài viết do Content Agent soạn thảo**, chờ Andy review trước khi chuyển vào `docs/`.

## Quy trình
1. Content Agent viết → lưu vào đây
2. Andy đọc, sửa nếu cần
3. Approve → chuyển file `.md` vào đúng thư mục trong `docs/`
4. Xóa file khỏi `tempo/` sau khi đã publish

## Cấu trúc file
- `bai-YYYY-MM-DD-ten-slug.md` — bài viết chính
- `bai-YYYY-MM-DD-ten-slug-linkedin.txt` — caption LinkedIn
- `bai-YYYY-MM-DD-ten-slug-facebook.txt` — caption Facebook
