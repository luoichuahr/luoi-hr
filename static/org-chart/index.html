Tạo sơ đồ tổ chức từ file Excel

Tải file mẫu về, điền danh sách nhân sự và cột "báo cáo cho", rồi đẩy file lên đây. Sơ đồ hiện ra ngay — kéo thả để thử phương án cơ cấu mới, xong thì xuất ra HTML, PDF hoặc PowerPoint.

📄
Kéo file Excel vào đây, hoặc bấm để chọn file
Nhận .xlsx · .xlsm · .xls — đúng theo file mẫu
1
Tải file mẫu
File Excel có sẵn cột chuẩn và 17 dòng ví dụ để xem cách điền.
2
Điền nhân sự
Mỗi dòng một vị trí. Cột "Reports To (EID)" điền mã của cấp trên trực tiếp.
3
Đẩy file lên
Công cụ kiểm tra lỗi trước: trùng mã, sai mã cấp trên, vòng lặp báo cáo.
4
Sửa và xuất
Kéo thả sắp lại cơ cấu, rồi xuất HTML / PDF / PPTX nhiều slide.
Dữ liệu của bạn không đi đâu cả. File Excel được đọc ngay trong trình duyệt trên máy bạn — trang này không có máy chủ nhận file, không lưu, không gửi đi.
