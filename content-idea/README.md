# content-idea/

Thư mục chứa **ý tưởng bài viết** Andy đã lên sẵn, chờ A_Content của HR Agent hoặc Content Agent của luoi-hr thực hiện.

## Cách dùng
- Mỗi ý tưởng = 1 file `.md`
- Đặt tên: `idea-ten-chu-de.md`
- Khi giao cho Content Agent: nói "viết bài theo idea `content-idea/ten-file.md`"
- Sau khi Agent viết xong và bài đã vào `tempo/`: xóa hoặc đánh dấu `[DONE]` vào tên file

## Template ý tưởng
```
# [Tiêu đề dự kiến]

## Mục tiêu bài
[Bài này giúp reader làm được gì?]

## Đối tượng
[HRBP / Recruiter / C&B / HRM / Tất cả]

## Ý chính muốn truyền đạt
- ...
- ...

## Từ khóa SEO (nếu có)
- ...

## Ghi chú thêm
[Bất kỳ yêu cầu đặc biệt nào]
```
